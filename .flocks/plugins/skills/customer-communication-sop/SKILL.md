# Customer Communication SOP

Use clear, calm and evidence-bound language.

## Communication Rules

- Start with what happened, affected scope and current risk.
- State confidence and evidence limitations.
- Separate immediate actions from follow-up actions.
- Avoid blame, speculation and alarmist wording.
- Use “疑似”, “需要进一步核查”, or “不足以确认入侵” when evidence is incomplete.

## Safe Recommendations

- Verify logs and telemetry.
- Validate vulnerability exposure.
- Patch or mitigate vulnerable components.
- Increase monitoring for IOC and techniques.
- Review access control and incident response timeline.

Do not tell the customer that Flocks executed containment unless a human-approved external process did so.
